# 发布校验与复现层级

## 可以直接核对

所有文件可浏览；SOURCE_MANIFEST.json记录从原工作区选出的文件及字节级SHA256。scripts/release/check_release.py检查原始来源一致性、Python语法、文件大小及禁用资产类型；tests_release检查独立关系目标的边界、方向、配对幅度及loss定义。整个检查不调用VLA或GPU。

## 需要外部资产

端到端训练和仿真需要VLA权重、对应动作头/本体投影器、LIBERO环境与初态、RLDS或bank，以及各阶段的来源清单。历史configs、worker使用原机器路径和冻结哈希。上传了代码不代表外部资产随之上传，也不代表新机器已完成GPU验收。

不要删除来源核验来让旧签名通过。迁移时使用新配置、新输出和新清单，并对PNG预处理、原生动作、重放状态与相机时钟重新核验。对历史源码的目录结构保持不变，避免动态加载错误模块。

## 历史依赖管理

research_runs仅包含经方法依赖追踪选出的源码、配置和测试，没有历史训练状态。部分fix目录虽然名称像失败版本，其中仍包含当前方法调用的公共代码，故纳入源码依赖；普通失败日志和重复提交脚本未纳入。依赖清单在SOURCE_MANIFEST.json的historical_run_dependencies字段。

原记录位于archive/research_records，其中“待提交/已完成”描述对应记录当时日期；当前导航与结果索引优先。它们是研究来源，不是新的运行指令。早期archive/negative_results/early_sources为关键实现片段，不声明是完整可独立运行的旧工程。

## 结果与证据

任务成功率是策略完成任务的比例；CASR是在同起点clean成功条件下补丁诱发失败的比例。套件任务等权均值与总失败/总clean成功不是总能互换。内部替换/动作恢复只列为机制诊断，不能计入PNG攻击成绩。

最终PNG与对应来源哈希单独保留。历史UADA500与本地混合池4000次训练不是同预算对照；联合模型固定旧PNG评测不是联合模型重训练。
