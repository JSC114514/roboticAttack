# 当前方向与研究决定（2026-10-26）

研究问题是：腕部相机的观察位置发生变化时，能否恢复正常控制，同时保留对真实操作状态变化的响应？动机来自局部控制对腕部信息的依赖；相机变化与物体真实移动需要不同的控制反应。

## 已经完成什么

### 视角适配：1,440个完整回合

固定官方四套件联合OFT；在腕部DINO block18—22训练rank8、alpha8低秩参数，共245,760参数，其余模型冻结。每配置1,000次更新、seed42。专家训练512对、验证320对；相机训练与验证各80个状态，轨迹分离。相机训练局部x/z偏移±5/10mm。

完整评测使用四套件另外8个开发任务，每任务初态18—21；每起点原生及局部x/z各±15mm，共160回合／配置，9配置合计1,440回合。

| 方法 | 正常任务成功 | 相机偏移任务成功 |
|---|---:|---:|
| 原模型 | 32/32 | 124/128 |
| 仅专家监督 | 32/32 | 124/128 |
| 图像增强 | 31/32 | 124/128 |
| 一致性权重0.1 | 32/32 | 126/128 |
| 一致性权重1 | 32/32 | 128/128 |
| 一致性权重10 | 31/32 | 127/128 |
| 约束容差0% | 32/32 | 125/128 |
| 约束容差10% | 32/32 | 126/128 |
| 约束容差25% | 32/32 | 125/128 |

这是任务成功数，越高越好。权重1在这批开发条件下救回4个原失败；新增约束没有超过普通一致性。

### 相机与目标响应：279个有效短分支

三个模型冻结，使用Spatial0/1、Object0/1、Goal1、Long0，初态42/43。12条候选轨迹中11条可选；Long0初态42没有符合可见性条件的观测。每条选目标可见、未接触、未抓持且距离最近的缓存状态。

真实目标沿机器人基座X轴移动−2/0/+2cm，腕部相机沿局部X移动−2/0/+2cm，交叉9条件。每模型93个有效分支、6个无效变体、0缺失；每分支执行8步。物理变体异常保留，三模型使用同一有效集合。

相机不动时，权重1相对原模型的“目标位移引起的接近变化”分别为：

| 真实目标位移 | 接近响应差 | 任务→轨迹bootstrap 95%区间 |
|---|---:|---:|
| −2cm | −0.377mm | [−0.979, −0.009]mm |
| +2cm | −0.159mm | [−0.531, +0.060]mm |

负值表示目标位移引起的接近变化比原模型小，不等于“机械臂少移动这么多”，也不等于最终任务失败。相机偏移条件下差异没有一致恶化方向；接触、抓持未形成跨任务一致下降。最新证据不支持把“普通一致性破坏空间响应”作为新增方法的既定动机。

## 当前决定

保留一致性权重1为有效适配配置，停止追加空间保持约束。论文的方法缺口仍需从真实控制问题中确定：已有结果展示视角适配有效，尚未形成超过已有一致性／腕部适配工作的技术创新。本次整理不启动新训练。

历史DINO干预提供控制路径依据；它不自动说明相机适配的独特机制，也不自动提供更强补丁。后续每个实验都对应一个明确问题，再决定是否需要新技术。
