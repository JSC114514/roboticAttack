# 单变量参数消融与冻结确认

## 目的与范围

权重、学习率、训练长度和batch分别改变，基线同样扫描；开发集选实际训练配置，再用三个种子和新起点确认。

## 固定设置

默认500×50更新；长度快照固定2000 outer调度；batch用均值梯度累积并另记样本反传量。没有触发batch4/8。

补丁50×50 RGB、位置[26,137]；源模型为四套件联合OFT。模型参数冻结，训练保留DINO+SigLIP自然梯度。训练池候选1920观测/240专家轨迹/24任务，实际访问数与更新次数分别记录。跨模型阶段不读训练银行，也不重新训练。

## 配置、源码和结果

- [冻结配置](configs/SWEEP.json)：保留本次原始协议和来源路径。
- [结果说明](FINAL_ABLATION_SUMMARY.md)：计数、任务成功率和CASR分开报告。
- [逐回合CSV](../../results/episodes/sensitivity/)：可重算的精简记录。

原始测试源码放在`source_tests/`用于说明运行检查，依赖原始父阶段资产及部分集群模块，不作为发布版CPU测试套件；发布检查在仓库根`tests_release/`。`reports/`只含精选科学结果，不包含旧完整运行收据或可跳过前置检查的标记。

本目录没有Slurm提交器、任务脚本、资源轮询、视频、模型权重或优化器文件。机器路径通过独立运行目录配置；冻结配置和原始源码签名用于追溯，不能用注释版冒充历史字节身份。
