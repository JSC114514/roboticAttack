# 跨模型原生PNG与分支恢复

## 目的与范围

固定四配置各三种子，比较Adapter-Pro和π0.5；另外检查Adapter同状态DINO/SigLIP恢复，不重新训练。

## 固定设置

每目标80起点×16条件=1280，合计2560原生回合；Adapter480恢复回合。两模型分别使用原生接口与自己的clean分母。

补丁50×50 RGB、位置[26,137]；源模型为四套件联合OFT。模型参数冻结，训练保留DINO+SigLIP自然梯度。训练池候选1920观测/240专家轨迹/24任务，实际访问数与更新次数分别记录。跨模型阶段不读训练银行，也不重新训练。
