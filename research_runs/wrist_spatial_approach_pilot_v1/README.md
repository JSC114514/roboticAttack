# 四套件混合数据：目标接近方向反转（有界小试）

**冻结单个Goal checkpoint，数据仍来自四套件24个训练任务。**本轮不声称DINO独有机制，也不预设优于UADA。原实验全部只读。

## 本轮方法

对固定首阶段交互实体，使用碰撞几何中心作为距离参考；抽屉使用把手、炉具使用按钮，不按可见性改选实体。该参考点不是精确抓取点，多阶段任务本轮只覆盖固定首个交互对象。目标物体不移动、没有渲染反事实、没有表示替换。

从原始960帧索引对应的轨迹中，重放已保存种子/初态/动作；不再使用原五个进度帧。拟合初态40/41、验证42/43，各48条轨迹。每轨迹取首次固定目标接触前最多五个原生决策，共最多240/240帧。无接触、不可见、Goal clean首槽不接近的记录完整保留为无效目标，不能宣称原缓存本来就包含这些新帧。源轨迹来自各套件原生策略，不等于当前Goal模型能完成它们。

令u为当前末端到交互参考点的单位向量。将干净Goal模型的全部8槽平移控制目标，投影至“沿u的分量不大于-5mm”的有效OSC目标集合，其他方向采用最小改动解。5mm是**控制器目标位移**，不是实际末端位移，更不是固定间距控制。动作目标来自几何规则；不是旧反事实DINO动作教师。

训练损失是三维控制目标MSE/0.05²。完整原生双分支前向；腕部DINO与SigLIP均回传到同一张50×50 RGB补丁。训练不裁剪预测控制量以免饱和切断梯度，部署按原生控制器裁剪，离线结果同时报告实际裁剪后的量。保留前视、语言、本体状态；冻结所有模型权重。固定位置[26,137]，无EOT，无额外特征/读出器/动作偏差损失堆叠。

对照为同池、同平移DoF、同双分支梯度、同更新数的clean参考远边界；不是原专家参考UADA。现有Spatial UADA500 PNG作为单独的迁移部署参考，不能把这种跨checkpoint比较写成公平重训练胜负。

几何方法与远边界对照的目标强度并未匹配，比较的是两套完整目标构造方法；不能把差异单独归因于空间机制。旋转与夹爪没有额外约束，必须核对其变化，不能把任何任务失败都写成空间误导成功。

## 顺序与预算

1. 两个capture worker重放，记录原生相机回调内的RGB/物理标签及控制器配置，保存实体审计和预览。
2. CPU覆盖核验：如四套件任一套件没有有效拟合样本，停止后续训练，报告Goal模型/数据覆盖问题，禁止暗中退回单套件。
3. 两方法×seed42/43，四张独立PNG，每张4000次**实际更新**；最多两个GPU worker并发。统一Adam、lr0.002、warmup20/cosine。同种子同初始PNG与固定样本顺序，按套件均衡、套件内任务均衡采样。仅使用有效拟合记录优化；无效记录与原因完整报告。
4. 每500步保存补丁、Adam、计数与全部随机状态；仅在四组训练均完成后选择最终4000步，不按验证表现挑检查点/种子。
5. 真实PNG部署：同一Goal模型，四套件40任务、初态0/1。优先Goal。先跑每个clean起点；clean失败的起点不继续浪费其余条件，也不计攻击成功。clean成功起点比较两初始PNG、四训练PNG和旧UADA PNG。至多640回合，实际取决于clean成功数。每控制步保存实际末端位置、距离、接触、抓持；没有几何标签的回合仍可评测任务成功，但必须报告标签缺口。
6. 离线验证每条验证轨迹最后一个预定采样点（最多48张），报告原生PNG动作、控制目标匹配、方向与无效原因。验证数据不拟合、不选优。

CASR、相对初始PNG新增失败和方法对照差异均按真实同起点配对计算；任务→起点bootstrap2000次，不把帧/槽位当独立样本。已查看过的任务属于开发背景，不称独立确认或任意环境通用。

## 资源与手动入口

- Capture与评测：每worker 1×4090、4CPU、12G；训练：1×4090、4CPU、16G。
- CPU覆盖核验/选择/报告：2CPU、4G。全流程最多同时两张GPU，依赖等待不占GPU。
- 初估约2–4小时、不含排队，尚无本流程吞吐实测；30秒心跳更新ETA、RSS与CUDA allocated/reserved峰值，失败成本单列。
- 接口检查在GPU任务启动时执行：PNG像素一致、原生动作及可微反归一化误差≤1e-5、零替换恒等、双分支有限且非零梯度、模型冻结。检查失败立即退出；不会自动放宽、重试、换卡。

```bash
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --preflight
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --dry-run
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --submit
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --status --slurm
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --watch --slurm
bash research_runs/wrist_spatial_approach_pilot_v1/run.sh --resume
```

仅--submit/--resume调用sbatch，由用户手动执行。其他入口不提交。相同版本有活动任务时整链去重，已封存阶段/候选/回合不重算。依赖使用afterok并自动终止无效依赖等待；CPU最终报告使用afterany以保留失败。含糊的sbatch响应拒绝再次提交，须人工核对Slurm。新旧代码或输入哈希变化时拒绝续跑。

主要输出：results/COVERAGE.json、CASR.csv、STATUS.json、RESULTS.md；逐步真实运动在evaluation/episodes下的STEPS.parquet。没有实现固定间距收敛、共享补丁效果或CASR提升之前不作这些声明。
