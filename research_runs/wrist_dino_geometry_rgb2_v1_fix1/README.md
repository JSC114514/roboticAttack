# 2倍几何目标：共享RGB可实现性短试验

**fix1工程修复：**原版缓存被两处微小跨次RGB差异中止，尚未训练。见[REPAIR.md](REPAIR.md)。不提高RGB/本体容差；历史RGB不匹配时，只有采样时刻完整物理、物体/相机位姿及传感器时钟指纹全部严格相同，才接受当前同帧clean/CF配对。否则在加载VLA前的重放检查中停止。原13轨迹/65帧按签名和哈希审计复用，不删除失败任务。旧数据、日志、成本只读。

已完成的理想干预在10起点上正/负方向失败4/3回合，仍不能说明RGB补丁有效。本轮固定正方向为开发目标，检验真实PNG能否复现作用；该方向选择是探索性选择，4比3并不证明优越性。两候选复用原投影匹配和完整匹配损失，不命名为新方法，不自动长训练。

## 固定数据与训练

原24个训练任务分布于四套件；始终只用Spatial checkpoint。初态40/41的48轨迹、每轨迹五个固定进度点，共240拟合观测；42/43同规则共240验证观测，轨迹分离。并非新的验证任务。动作响应不参与选样，no-target及工程失败保留。闭环为此前5个Spatial任务、初态44/45的10个已查看开发起点，不称为独立确认。

按原种子、初态、已保存8×7动作及实际执行槽位重放至最后一个所需观测，不重新调用策略生成轨迹。原缓存画面及本体状态对齐后，在原生sensor采样时刻用已核验2×渲染代码生成目标：原位移截断到30mm后整体乘2，上限60mm，目标实体选择/高度不变。重新编码两方向的DINO目标；不是将旧特征差乘2。只渲染可视geom，物理状态、相机和时钟指纹不变。异常恢复钩子。

每候选一张共享50×50腕部RGB补丁，固定位置[26,137]，同一seed42初始PNG。冻结模型，无EOT、动作损失、接受门槛或验证集选检查点。每图访问20次，共4800候选更新；Adam固定lr0.002，与旧短试验相同学习率。投影损失只约束原有归一化投影；完整损失=投影+正交残差。梯度仅来自DINO，实际PNG会同时改变DINO和SigLIP输入。

另预选12个拟合观测（按任务固定顺序每隔一个任务、初态40、阶段轮换，不看响应），各训练独立PNG100次作诊断；每候选额外1200更新。单图与共享访问次数不同，完整报告，不单凭差距断言共享目标冲突。单图PNG仅作拟合诊断，不混入通用补丁闭环。

## 原生核验与闭环

首批GPU核验PNG量化/原生预处理、DINO特征、双分支替换等价、有限非零梯度和冻结权重。最终仅部署保存的PNG，恢复分支只用于离线诊断。验证240帧记录clean、初始PNG、UADA及两共享PNG的表示距离、目标投影、完整8×7动作和方向一致性；拟合12帧配对比较单图、共享与初始PNG。模型所有分支均原生运行。

按哈希、种子、checkpoint和reset状态/相机/本体指纹核实复用clean、初始随机、UADA共30回合，只新增两共享PNG各10回合，共20回合。每个新回合在执行动作前与保存的clean原数组逐项严格比较；失配保存原数组和差异，不能当作攻击成功。保存全部动作、实际执行槽位、同当前观测的clean参考预测、末端/夹爪及少量关键帧。参考预测不执行。

## 手动入口、资源和监控

```bash
bash research_runs/wrist_dino_geometry_rgb2_v1_fix1/run.sh --preflight
bash research_runs/wrist_dino_geometry_rgb2_v1_fix1/run.sh --dry-run
bash research_runs/wrist_dino_geometry_rgb2_v1_fix1/run.sh --submit
bash research_runs/wrist_dino_geometry_rgb2_v1_fix1/run.sh --status --slurm
bash research_runs/wrist_dino_geometry_rgb2_v1_fix1/run.sh --watch --slurm --interval 30
```

最多同时2张4090：目标缓存2worker按任务分片，每worker4CPU/12G；两候选训练各1张、4CPU/16G；随后单卡原生评测4CPU/12G；CPU汇总2CPU/4G。阶段不重叠，等待依赖不占GPU。上轮4800共享更新实测约7分钟，20回合理想干预约6分钟；新缓存、额外单图和验证吞吐尚未实测，整轮暂估30–50分钟，不含排队和代码准备，不保证截止时间。

只在用户运行--submit时提交。活动作业去重；队列失败停止提交；提交响应不确定不自动重试或取消；失败依赖用afterany推进，GPU后继先检查产物，失败则在加载模型前退出并保留成本。相同命令可续跑，缓存按轨迹、训练按遍历及单图、评测按观测/回合保存。每30秒独立心跳；记录RSS HWM、CUDA allocated/reserved峰值、设备、实际优化/无目标次数、梯度、像素变化和失败成本；Slurm sampled MaxRSS单列。

results/RESULTS.md直接报告新失败、随机失败重合、CASR；OFFLINE_SUMMARY.csv给出任务→轨迹重采样区间和阶段/表示指标的原始来源。数据完整报告，无统一效果门槛，不用特征MSE代替任务失败，不把理想内部干预的40%写成RGB结果。此前单帧1×试验与本轮在目标强度、阶段覆盖及每帧访问次数上不同，不能把变化单独归因于某个组件。
