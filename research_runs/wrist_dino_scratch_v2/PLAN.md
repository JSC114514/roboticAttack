# Wrist-DINO Scratch V2：独立重跑与自动测试

2026-09-28 冻结。V2 从 seed42 随机 RGB 开始，**不读取** V1 的 250 轮补丁、旧 UADA2000/2200 补丁或旧受扰经验库。基础方法、损失、EOT、位置和三臂比较沿用 V1 方案；输出仅进入本目录。原 Exploring `VLAAttacker/white_patch/UADA.py` 保持只读，训练使用其独立派生副本。

训练：腕部单个 3×50×50 补丁，Front 干净；250 轮共同前缀，使用本次前缀在 Object 原训练初态采集受扰轨迹并评分。UADA、均匀片段、DINO 加权片段三臂从相同 RGB/Adam/日程/随机状态继续到总 1000 轮，各保存 500/750/1000。三臂只在片段抽样上不同；500/750 为同一 1000 轮日程的中间点，不当作独立训练。

测试：九张补丁在训练全完成后由 CPU 作业核验文件哈希、来源、RGB、对齐和数值外观指标，写 `AUTO_VALIDATION.json`。这**不是人工视觉认可**，外观仍需事后看 PNG。核验成功才自动启动四套件各 10 任务×10 初态、9 条件共 3600 个闭环攻击回合，随后自动合并统计。Object/Spatial/Goal 为主要展示，Long 完整记录但次要；按同 task/state/rollout seed 配对。只用一个训练种子，不能把 500/750/1000 当成三次独立重复，既有开发初态也不是全新盲测。

作业顺序：4090 前缀 → 3090 Object 采集阵列 → CPU 合并 → 4090 三臂训练阵列 → CPU 自动核验 → 最多 8 张 3090 四套件测试阵列 → CPU 汇总。任一阶段失败，`afterok` 会阻止后续阶段执行。只有用户手动运行提交脚本才会向 Slurm 提交，助手不得自动提交。

估计（不含排队）：前缀约 50 分钟；采集/合并约 10–30 分钟；三臂并行续训约 2.5–3.5 小时；四套件测试约 2–3 小时；总计约 6–8 小时，资源冲突可能延长。若正式测试未赶上明日组会，先报告训练/补丁及核验状态，不把旧 window 结果当作 V2 结果。
