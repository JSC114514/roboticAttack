# 腕部不对称性：两路线机制筛查

冻结Goal checkpoint；不训练新PNG、适配器或LoRA。校准Goal任务0/1/3/5/6/7、初态40/41共12轨迹58观测；核验42/43共12轨迹60观测。不沿用旧攻击的正在接近筛选。四套件混合补丁训练池和旧实验均只读。核验起点固定为每条轨迹最早缓存决策；这些起点属于开发背景，不称独立确认。

先按原种子、初态和保存动作逐控制步重放；核对缓存RGB、本体、传感器采样时刻的精确物理/相机/时钟指纹。每分支重建新环境并恢复共用构造RNG，重放同一前缀，不只恢复qpos/qvel而丢失控制器状态。clean参考最多64控制步，原生8步动作块；clean提前结束则定义该起点共同窗口。分支提前结束不补造帧。

## 非攻击

clean；前视/腕部各模糊和延迟，共5原始条件。模糊224RGB、sigma2、13核、reflect边界；延迟是真实8控制步前图像。起点在第0决策时，历史来自固定10步等待过程，不用复制当前图像冒充过去。延迟只修改策略输入，原生传感器和时钟不动。

每失效增加减弱受损视角/减弱另一视角：两视觉分支输出空间token在投影前按`fit_mean + .5*(value-fit_mean)`修改。均值只来自58条fit图像，DINO的CLS/register保持原生。13条件×12起点=156短分支。事后最佳选项只是固定候选集内潜力，不是部署恢复器或理论上限。

预警诊断每视角PCA8→上一时刻PCA特征+本体变化→岭回归预测当前特征。正则.1/1/10/100，5折按轨迹；每折内部重拟合PCA和标准化。仅用连续缓存决策对。clean折外残差标定，90/95%只是报告操作点，不作科学通过门槛。对照为特征原始变化量和Laplacian清晰度；核验集不调模型、阈值或选方向。AUROC以起点/条件的首个决策分数预测共同窗口内未能首次接触，而非把动作帧作样本。提前量相对配对clean首次接触时刻，不声称精确预测不可逆失败时刻。

## 补丁

正确关系seed42和同条件UADA全部7维seed42的封存4000次最终PNG。固定50×50/[26,137]/无EOT/原生双分支。每张：持续、仅首块、clean相机路径、同幅随机相机路径及其无PNG对照；另clean相机回放恒等对照。12条件×12=144，共用12clean后总288短分支，最多18432控制步。

相机反事实使用`copy.copy`的同一已实现MuJoCo模型和`mj_copyData`的采样时完整数据，不从XML重新随机建场景。仅修改副本的世界相机pose，原生sensor返回原图，反事实图走独立策略输入。逐次恢复原GL上下文并核对原环境指纹；窗口起点使用保存的原相机采样MjData，而非控制步结束状态。零姿态NRMSE<=1e-4，clean相机回放动作误差<=1e-5；不放宽或反复重试。

随机平移长度和SO(3)角度逐控制时刻取对应PNG相机回放供体，方向/旋转轴由固定seed决定。同一PNG有/无补丁随机条件共用幅度和方向。若供体任务先结束，两随机条件均持有终止幅度，标记匹配证据缺口；相机因果比较只使用供体有真实样本的共同前缀，不能把延拓算作实测匹配。

单独“持续PNG更强”不证明相机反馈；主要报告扣除各自无PNG相机效应后，clean相机回放相对同幅随机变换的接触改善。内部相机/特征操作不能计作可部署攻击成绩。输出实际末端/目标位置、接触、抓持、可见性和8×7动作；控制命令不写成实际位移。短窗口无接触不是完整CASR。

## 资源、入口与交付

共用GPU采集→CPU校准→两路线各一GPU并行→CPU汇总/视频。最多2张4090，每worker4CPU/12G；CPU2CPU/4G。预留2–3小时GPU墙钟，不含实现排队；每GPU阶段限时3h，首批4起点更新实测。每30秒心跳、RSS/CUDA峰值、设备/吞吐/失败成本。完整分支续跑，接口失败释放GPU，依赖等待不占GPU。

```bash
bash research_runs/wrist_view_asymmetry_screen_v1/run.sh --submit
bash research_runs/wrist_view_asymmetry_screen_v1/run.sh --status --slurm
bash research_runs/wrist_view_asymmetry_screen_v1/run.sh --watch --slurm
bash research_runs/wrist_view_asymmetry_screen_v1/run.sh --resume
```

`--prepare`仅CPU来源核验，`--check`实际批处理启动入口检查，`--dry-run`打印依赖图不提交，`--report`生成当下完整配对的部分报告。提交前查同前缀所有任务，无法查询队列则拒绝盲目重复提交；不自动取消、换卡或扩展实验。源码签名固定，变更后旧收据不会悄悄复用。

单视角视频集中`research_videos/wrist_view_asymmetry_screen_v1_singleview/{MP4,IDE_WebM}/条件/{front,wrist}/`，无拼接/叠字；特征干预无法在RGB直接画出，元数据明确标注。文件名task_success仅表示短窗口内任务完成，0不代表完整任务失败。两格式完整解码检查，IDE是否播放仍以用户观察为准。

科学判断完整报告效应、按任务→轨迹区间和缺口，不预设统一高分门槛。若两路线均有证据，优先非攻击；若仅一条有支持则集中该路线。结果用于讨论，不自动启动新方法训练或扩大评测。
